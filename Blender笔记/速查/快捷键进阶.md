# 快捷键进阶路线

已掌握：`G/R/S`、`Tab`、`1/2/3`、`E`、`I`、`Ctrl+R`、`Ctrl+B`、`Ctrl+A`、`F3`

| 阶段 | 新增快捷键 | 用途 | 已熟练 |
| --- | --- | --- | --- |
| Stage 0 | `G G` / `Alt+LMB` / `Ctrl+Alt+LMB` | 边滑动 / 选环 / 选圈 | ⬜ |
| Stage 0 | `Ctrl+E`（边菜单）→ Mark Sharp / Mark Seam | 标记硬边与缝合边 | ⬜ |
| Stage 1 | `Ctrl+Shift+B`（顶点倒角）/ `L`（选连通）/ `Shift+G`（选相似） | 批量选择与清理 | ⬜ |
| Stage 2 | `Alt+D`（链接复制）/ `Shift+Ctrl+Alt+C`（设原点） | 实例与原点管理 | ⬜ |
| Stage 3 | `Ctrl+E → Mark Seam` | 标记缝合边（UV 剪刀线） | ⬜ |
| Stage 3 | `U`（UV 菜单） | 展开：`Unwrap` / `Smart UV Project` / `Lightmap Pack` / `Follow Active Quads` / `Cube Projection` / `Project from View` | ⬜ |
| Stage 3 | `4`（UV 编辑器） | **UV 岛选择模式** ⭐ 排布/缩放时最常用 | ⬜ |
| Stage 3 | `P` / `Alt+P` / `Shift+P` | 钉住 UV / 取消钉住 / 选中所有已钉住 | ⬜ |
| Stage 3 | `Ctrl+L` / `Y` | UV 编辑器里选整岛 / 拆开「粘住」的选择 | ⬜ |
| Stage 3 | `Alt+V` | Stitch 缝合被切开的 UV | ⬜ |
| Stage 3 | `Select → All by Trait → Overlap` | ⭐ 查重叠（烘焙前必查） | ⬜ |
| Stage 3 | `Select → All by Trait → Winding` | ⭐ 查镜像 / 翻面的岛 | ⬜ |
| Stage 4 | `Ctrl+Shift+LMB`（Node Wrangler 预览节点） | 材质调试 | ⬜ |
| Stage 4 | `Ctrl+Shift+T`（NW 一键 PBR 贴图组）/ `Ctrl+T`（补贴图坐标） | 导入整套 CC0 材质 | ⬜ |
| Stage 4 | `Alt+R`（NW 重载贴图）/ `Shift+P`（装 Frame） | 节点树维护 | ⬜ |
| Stage 4 | `Alt+S` ／ `Shift+Alt+S`（Image Editor 存盘 / 另存） | **烘焙完立刻存盘** | ⬜ |
| Stage 4 | Texture Paint：`F` 笔刷大小 ／ `Shift+F` 强度 ／ `[` `]` 微调 | 手绘细节 | ⬜ |
| **Stage 5** | `F` / `Shift+F` / `[` `]`（Sculpt） | 笔刷大小 / 强度 / 大小微调 | ⬜ |
| **Stage 5** | `X`（Sculpt）/ `Ctrl` 按住 / `Shift` 按住 | 切换正负方向 / 临时反向 / 临时平滑 | ⬜ |
| **Stage 5** | `R` 拖动 / `Ctrl+R`（Sculpt） | 设 Voxel 或 Dyntopo 的分辨率（带网格预览）/ 执行 Remesh | ⬜ |
| **Stage 5** | `Alt+H` / `Shift+H` | 恢复全部隐藏 / 只显示选中（**retopo 前必按 `Alt+H`**） | ⬜ |
| **Stage 5** | `U → Cube Projection` | 岩石等不规则体块的一步式 UV（不读缝合边） | ⬜ |
| **Stage 6** | `Shift+N`（重算法线）/ `M → By Distance` | 导出前清理 | ⬜ |
| **Stage 7** | `Shift+Tab` | ⭐ **开关吸附**（Kit 拼装对位必备；模式在右键面板选 Vertex / Edge / Face） | ⬜ |
| **Stage 7** | `Ctrl+J` | 合并物体（降 draw call；**同区域 + 同材质 + 永不动的静物才合**） | ⬜ |
| **Stage 7** | `I`（旋转/缩放后按） | ⭐ 打关键帧（转台：第 1 帧 `R Z 0` → `I`；第 120 帧 `R Z 360` → `I`） | ⬜ |
| **Stage 7** | `F12` / `Ctrl+F12` | 渲染单帧 / 渲染动画 | ⬜ |
| **Stage 7** | `Alt+D` vs `Shift+D` | 链接复制（省内存）／普通复制（可改形状）——区别见 `08-场景组装与作品集/03` | ⬜ |
| **Stage 7** | `Overlays → Statistics` | ⭐ 读真实面数（**读 Tris 那栏，不是 Faces**） | ⬜ |

| **支线·绑定** | `Tab` / `Ctrl+Tab` | Object ↔ Edit / 模式菜单（在 Armature 里切 Pose Mode） | ⬜ |
| **支线·绑定** | `E`（Edit Mode 选中骨） | 挤出下一节骨（建骨链的基本动作） | ⬜ |
| **支线·绑定** | `Ctrl+P → Armature Deform` | 绑定（**顺序：先选网格，最后选骨架**） | ⬜ |
| **支线·绑定** | `Alt+P` | 清除父子关系（Clear Parent） | ⬜ |
| **支线·绑定** | `Alt+G` / `Alt+R` / `Alt+S`（Pose Mode） | 清除姿势的位移 / 旋转 / 缩放（回 rest pose） | ⬜ |
| **支线·绑定** | `Ctrl+A → Apply Pose as Rest Pose`（Pose Mode） | 把当前姿势烤成新 rest pose（⚠️ 不可逆，先 `Ctrl+Alt+S`） | ⬜ |
| **支线·绑定** | `Ctrl+N`（Edit Mode） | ⭐ **Recalculate Roll**（Global ±X/±Z · Active Bone · View · Cursor） | ⬜ |
| **支线·绑定** | `Ctrl+R`（Edit Mode）/ `Alt+R` | 手动 Roll / 清除 Roll | ⬜ |
| **支线·绑定** | `Armature → Names → Auto-Name Left/Right` | 按 X 坐标自动加 `.L` / `.R` 后缀 | ⬜ |
| **支线·绑定** | `Armature → Symmetrize` | 生成对称的另一半骨 | ⬜ |
| **支线·绑定** | `Ctrl+LMB`（Weight Paint） | ⭐ 点骨 = 选中该骨对应的顶点组 | ⬜ |
| **支线·绑定** | `F` / `Shift+F`（Weight Paint） | 笔刷大小 / 强度 | ⬜ |
| **支线·绑定** | `Weights → Normalize All / Limit Total` | 收口：权重和 = 1 / 每顶点 ≤4 影响 | ⬜ |
| **支线·动画** | `I`（Pose Mode） | 插关键帧（⚠️ 5.2 起 `Only Insert Available` 默认开，可能「按了没反应」） | ⬜ |
| **支线·动画** | `T` / `V`（Graph Editor） | 插值类型（Bezier/Linear/Constant）/ 手柄类型（Auto Clamped/Vector/Free） | ⬜ |
| **支线·动画** | `Pose → Animation → Bake Action` | ⭐ 把约束烘成关键帧（Visual Keying ON · Clear Constraints ON · Frame Step 1） | ⬜ |
| **支线·动画** | `Ctrl+L → Copy Constraints`（5.2 新增） | 批量复制约束到多根骨 | ⬜ |
| **支线·动画** | `Action Editor → Push Down` | 把 Action 压进 NLA 轨道（多动作共存） | ⬜ |
| **支线·动画** | `Ctrl+Alt+S` | ⭐ **Save Incremental**（改骨骼前必按，绑定是关联状态） | ⬜ |

> 每周只新增 3–5 个，不要一次背一堆。
> ⚠️ macOS 上 `Ctrl` 与系统快捷键冲突时会失效 → 一律 `F3` 搜命令名。
