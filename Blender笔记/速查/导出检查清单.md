# 导出检查清单（每个资产必过）

打印/复制版，与 [../07-资产规范与引擎导出/笔记.md](../07-资产规范与引擎导出/笔记.md) 同步。

## 一、几何

```
[ ] Ctrl+A → Apply Rotation & Scale（Scale 1,1,1，Rotation 归零）
[ ] 原点位置正确（道具：底部中心；角色：脚下；门：铰链处）
[ ] 面数在预算内（环境道具 ≤800 tri 移动 / ≤2500 tri PC）
    ⚠️ Blender 的 Faces ≠ Tris（Quad ×2）→ 编辑模式 Ctrl+T 三角化后数真实 tri
[ ] M → By Distance 合并重叠顶点
[ ] Shift+N 重算法线        ← ⚠️ 必须在 Merge by Distance 之后
[ ] 无孤立顶点、无内部面（Mesh → Clean Up）
[ ] Face Orientation 检查（Overlays）无红色 = 法线没有朝内
[ ] 无负缩放（`S X -1` 镜像）→ 否则引擎报 negative determinant
```

## 二、UV

```
[ ] UV 已展开 + 已 Pack Islands
[ ] 无重叠（若烘焙光照）
[ ] 棋盘格检查无拉伸
[ ] 硬边 / 倒角边与缝合边对齐
```

## 三、材质

```
[ ] 只用 Principled BSDF + 贴图，无 Blender 专有节点
[ ] Color 贴图 = sRGB；Normal / Roughness / Metallic = Non-Color
[ ] 材质数 ≤2（一个材质 = 一次 draw call）
[ ] 贴图已存盘到磁盘
```

## 四、场景

```
[ ] 删除空物体、参考图、相机灯光（若不需要）
[ ] 命名规范：类型_名称_变体_序号（Prop_Crate_Wood_01）
[ ] 一个资产一个 Collection
```

## 五、导出设置（GLB）

```
[ ] Format: glTF Binary (.glb)
[ ] Limit to: Selected Objects
[ ] Apply Modifiers: ON
[ ] +Y Up: ON
[ ] UVs / Normals: ON ；Tangents: OFF
[ ] Draco: 按需（level 6；⚠️ 先确认引擎支持解码 + 量化位数够）
[ ] Animation / Shape Keys / Skinning: OFF（静态道具）
[ ] ⚠️ 别用"隐藏"排除物体 → Limit to: Selected Objects
[ ] 已存为导出预设（导出窗口右侧栏 Operator Presets → +）
```

## 五点五、导出文件自验（在进引擎之前）

```
[ ] Khronos glTF Validator / Babylon Sandbox 打开过，无报错
[ ] 这一步不省：能区分「Blender/导出错了」还是「引擎导入错了」
```

## 六、骨骼 / 动画资产附加项

> 有骨架的资产在「一~五」之外**再加做**这一段。详见 [`../支线/绑定与动画/08-骨骼动画导出-GLB与FBX.md`](../支线/绑定与动画/08-骨骼动画导出-GLB与FBX.md) 与 [`10-工程实务补充`](../支线/绑定与动画/10-工程实务补充-帧率-根运动-外部动画源.md)。

```
【帧率与节奏（事前最低成本，事后最高成本）】
[ ] 场景 Frame Rate = 项目目标值（游戏项目通常 30）→ Properties → Output Properties → Format
[ ] 本项目全程未改过 fps（改过就要全量复查动画节奏）
[ ] 循环长度按「秒」核对过，并换算成当前 fps 下的帧数
[ ] Godot：导入面板 FPS（默认 30）与 Blender 场景 fps 一致
[ ] 硬挺道具（门/箱盖/阀门/电梯）确认用物体动画而非骨骼
     若用骨骼，写下理由（如要挂到手部骨 / 需要形变）
[ ] root-driven 还是 in-place 已决定，且本文件内所有动作一致
```

```
【格式选型】
[ ] 先定格式：默认 GLB；只有目标端明确要 FBX 才走 FBX
[ ] ⚠️ 有形状键 / 表情 / morph target → 必须 GLB（FBX 导出器不写 Vertex shape keys）

【几何 + 骨架】
[ ] 网格与骨架「两边」都 Ctrl+A → Rotation & Scale
[ ] 骨架是网格父级 / 网格带 Armature 修改器指向它
[ ] 有且只有一个 root 骨（否则 glTF 的 Remove Armature Object 失效）

【权重收口】
[ ] Weights → Clean
[ ] Weights → Normalize All
[ ] Weights → Limit Total = 4            ← 每顶点 ≤4 影响
[ ] 摆极端姿势验证：最大弯曲 / 最大伸展 / 扭转 90° 都不爆

【骨骼裁剪】
[ ] 要参与变形的骨勾了 Deform；控件骨 / IK target 没勾
[ ] Rigify rig → 导出勾 Export Deformation Bones only（FBX：Only Deform Bones）

【约束烘焙（用了约束 / IK 就必做）】
[ ] Pose → Animation → Bake Action
      Visual Keying: ON  ·  Clear Constraints: ON  ·  Frame Step: 1
[ ] 烘完滚动时间轴，表现与烘焙前一致

【动画组织】
[ ] 多动作已 Push Down 到 NLA 轨道并命名
[ ] 时间轴拨回动画起始帧
[ ] 循环动画：首尾帧逐通道一致（Cyclic F-Modifier 不参与导出）

【GLB 导出（骨骼）】
[ ] Data - Armature → Export Deformation Bones only: ON
[ ] Data - Armature → Use Rest Position Armature: ON
[ ] Data - Skinning → Bone influences = 4
[ ] Data - Skinning → Include All Bone Influences: OFF
[ ] Animation - Armature → Export all Armature Actions: ON（多动作；⚠️ 仅支持单骨架）
[ ] Animation - Armature → Reset pose bones between actions: ON（多动作）
[ ] Animation - Bake & Merge → Bake All Objects Animations: ON（有约束时）

【FBX 导出（只在必须时）】
[ ] Armatures → Primary / Secondary Bone Axis 已配（⚠️ FBX 骨骼是 -X aligned，Blender 是 Y）
[ ] Armatures → Only Deform Bones: ON
[ ] Armatures → Add Leaf Bones: OFF
[ ] Transform → Scale（默认 10）与 Forward / Up 按目标端设
[ ] Bake Animation → All Actions: ON（多动作）

【导入引擎后（骨骼专项）】
[ ] 骨骼数 ≈ DEF 骨数量（不是几百根 / 无 leaf bone 尾巴）
[ ] 播放动画：变形方向、幅度与 Blender 一致
[ ] 循环动画在引擎里 loop 不跳帧
[ ] 角色不穿地、不悬空、比例正确
[ ] Unity 专项：GLB 走 glTFast → clip 导入后**不会自动被分配**，要自己建 Animator/Controller
[ ] 帧率专项：引擎里的动作节奏与 Blender 一致（不一致先查两边 fps）
```

## 六点五、几何节点产出附加项

> 用几何节点生成 / 散布的资产，在「一~五」之外**再加做**这一段。详见 [`../支线/几何节点深入/05-实例化深入-Instances与性能.md`](../支线/几何节点深入/05-实例化深入-Instances与性能.md)。

```
【实例处理】
[ ] 已决定：Realize 还是保留实例
      · 目标引擎不支持 GPU 实例化 → Realize Instances
      · 实例带材质变体          → Realize（GPU Instances 不支持变体）
      · 嵌套超过 8 层            → 必须 Realize（否则渲染不出来且不报错）
[ ] Realize 之后才数面数（Statistics 读 Tris，不是 Faces）
[ ] 确认没有混用属性面板 Instancing（GN 实例与之冲突）

【几何清理】
[ ] Realize 后 M → By Distance（实例合并会产生重合顶点）
[ ] Shift+N 重算法线（变形 / 扫掠后法线常错）
[ ] 源物体都已 Ctrl+A → Scale（否则散布出来大小乱）

【导出开关】
[ ] Apply Modifiers: ON   ← ⚠️ 忘了这个 = 几何节点结果整个消失
[ ] GPU Instances（EXT_mesh_gpu_instancing）只在确认支持时开
      ⚠️ 硬限制：实例必须是网格 / 不能有子级 / 必须同属一个父物体 / 不支持材质变体
[ ] Geometry Nodes Instances 是实验性开关，导出后必须验证
[ ] Godot 不支持 EXT_mesh_gpu_instancing → Realize + Draco

【模拟 / Bake】
[ ] 用了 Simulation / Bake 节点 → 已先存 .blend 并 bake
[ ] 导出的是静态结果，不是某一帧的模拟状态
```

## 六点五、程序化材质转贴图后的附加项

> 材质是先拿程序化节点树算出来的（`支线/程序化材质`），在「三、材质」之外**再加做**这一段。详见 [`../支线/程序化材质/07-程序化到贴图-烘焙闭环与GLB.md`](../支线/程序化材质/07-程序化到贴图-烘焙闭环与GLB.md)。

```
【烘焙前】
[ ] 目标材质里有一个 Image Texture 节点，并且它是「选中 + 激活」的
    ⚠️ 手册原话：没有这样的节点，这个材质什么都不烤，且不报错
[ ] 渲染引擎 = Cycles（Pointiness / AO / Bevel 全是 Cycles Only）
[ ] UV 干净且无重叠（烘焙会把重叠区域互相污染）
[ ] Ctrl+A → Rotation & Scale（尤其是用了 Object 坐标时）
[ ] 每张目标图已定好分辨率与命名（_BaseColor / _ORM / _Height）

【烘焙时】
[ ] Base Color 用 Diffuse，且 Contributions 只勾 Color（不勾 Direct/Indirect）
    ⚠️ 用 Combined 会把场景灯光也烤进去
[ ] Roughness 用 Roughness pass；AO 用 Ambient Occlusion
[ ] Normal 用 Tangent 空间（默认）
[ ] Margin 已给足（1024 → 8~16px）
[ ] 程序化 Bump → 切线空间法线：属需实测项 → 稳妥做法是先保留 Height 灰度图

【烘焙后】
[ ] 每张图烤完立刻 Image Editor → Alt+S 存盘
[ ] 已回接标准 PBR 树：Base Color=图；ORM 走 Separate RGB（G→Roughness、B→Metallic）
[ ] AO 已接 glTF Material Output 的 Occlusion
[ ] 色彩空间：只有 BaseColor 是 sRGB，其余一律 Non-Color
[ ] ⭐ 烘焙前的 .blend 已单独留档（参数化版本一旦覆盖就回不去）
```

[ ] 面数 / draw call 符合预期
[ ] 控制台无导入报错
[ ] 截图存档：verify_blender.png + verify_engine.png
[ ] 把设置写进 07-资产规范与引擎导出/笔记.md 的「我的记录 → 目标引擎」
