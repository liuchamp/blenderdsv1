# 导出检查清单（每个资产必过）

打印/复制版，与 [../07-资产规范与引擎导出/笔记.md](../07-资产规范与引擎导出/笔记.md) 同步。

## 一、几何

```
[ ] Ctrl+A → Apply Rotation & Scale（Scale 1,1,1，Rotation 归零）
[ ] 原点位置正确（道具：底部中心；角色：脚下；门：铰链处）
[ ] 面数在预算内（环境道具 ≤800 tri 移动 / ≤2500 tri PC）
[ ] M → By Distance 合并重叠顶点
[ ] Shift+N 重算法线
[ ] 无孤立顶点、无内部面（Mesh → Clean Up）
```

## 二、UV

```
[ ] UV 已展开 + 已 Pack Islands
[ ] 无重叠（若烘焙光照）
[ ] 棋盘格检查无拉伸
[ ] 硬边 / 倒角边与缝合边对齐
```

## 三、材质

```
[ ] 只用 Principled BSDF + 贴图，无 Blender 专有节点
[ ] Color 贴图 = sRGB；Normal / Roughness / Metallic = Non-Color
[ ] 材质数 ≤2（一个材质 = 一次 draw call）
[ ] 贴图已存盘到磁盘
```

## 四、场景

```
[ ] 删除空物体、参考图、相机灯光（若不需要）
[ ] 命名规范：类型_名称_变体_序号（Prop_Crate_Wood_01）
[ ] 一个资产一个 Collection
```

## 五、导出设置（GLB）

```
[ ] Format: glTF Binary (.glb)
[ ] Limit to: Selected Objects
[ ] Apply Modifiers: ON
[ ] +Y Up: ON
[ ] UVs / Normals: ON ；Tangents: OFF
[ ] Draco: ON level 6（先确认引擎支持）
[ ] Animation: OFF（静态道具）
```

## 六、导入引擎后验证

```
[ ] 比例正确（UE5 需 Import Uniform Scale = 100）
[ ] 朝向正确（+Y Up）
[ ] 材质视觉与 Blender 基本一致
[ ] 面数 / draw call 符合预期
[ ] 控制台无导入报错
```
