# 常见坑汇总

> 各 Stage 结束时，把够通用的坑同步到这里。查问题先看这一页。

## 通用

- ❌ 在 Object Scale ≠ 1 的状态下建模 → 每次 `Ctrl+A → Scale`
- ❌ 快捷键对不上 → 按 `F3` 搜命令名，不要死记菜单位置
- ❌ macOS 与系统快捷键冲突的 `Ctrl` 会失效 → 见 `../00-基础/07-快捷键速查表.md` 的 Mac 一节，或按 `F3` 搜命令

## 倒角（Stage 0 / 1）

- ❌ 不开 Harden Normals → 倒角面被周围面平滑，白花面数还没效果
- ❌ 不开 Clamp Overlap → 密集细节处自相交、黑面
- ❌ 修改器顺序放反（SubD 在 Bevel 之前）→ 面数灾难
- ❌ Segments 给 3+ → 面数爆炸，游戏资产用 1–2 + SubD 即可
- ❌ 忘记勾 Mark Seam → UV 阶段要手动重标倒角边

## 拓扑（Stage 0）

- ❌ 为「更精细」疯狂加线 → 越密越难改，先用最少的线把形状定住
- ❌ SubD 后形状崩了就删线重来 → 先检查支撑线距离

## 硬表面（Stage 1）

- ❌ 布尔完不清理 → 三角面 / n-gon 一堆 → UV、烘焙全崩。**布尔只用来开洞，结构靠挤出**
- ❌ Bevel 修改器不设 Limit Method（默认 **None = 全倒**）→ 平面上的布线边也被倒，模型炸线。硬表面起手式是 `Angle = 30°–60°`
- ❌ 不做真实尺寸 → 进引擎后比例全乱
- ❌ 布尔 cutter 与表面共面 / 用 Fast 求解器处理重叠几何 → 算错 → 换 `Exact`，并让 cutter 明显穿透
- ❌ Mirror 之后（Apply 后）不 `Shift+N` → 镜像侧法线朝内，渲染发黑、布尔出负体积
- ❌ 在布尔生成的碎边上直接大倒角 → 沿碎边炸开 → 先清理，或用 Bevel Weight = 0 排除
- ❌ 修改器顺序错：Bevel 在 SubD 之后 → 面数 ×4ⁿ 灾难
- ❌ 把螺丝、铆钉这类纯视觉细节做成独立物体 → draw call 爆炸（做进同一网格，或用 Normal 贴图）
- ❌ 该分离的没分离（门/盖子做成一体）→ 后期要做动画时整个重来
- ❌ 分离件忘了把原点设到功能点（铰链/把手）→ 动画时绕几何中心转

## 非破坏性 / 资产管理（Stage 2）

- ❌ Mirror 原点不在对称轴 → 模型撕裂（Clipping 能缓解但别依赖，**原点才是根治**）
- ❌ ~~修改器顺序错：SubD 在 Mirror 之后会在接缝处产生硬边~~ → **因果说反了**。Mirror 先执行（排 SubD 之上）本身是对的；接缝硬边第一嫌疑是 **Merge / Merge Distance / Clipping / 法线**，顺序最后才怀疑
- ❌ 用了新的 **Array（5.0 几何节点版）但没开 `Realize Instances`** → Merge / Boolean 全没反应。要 Merge、要布尔、要导出成单一网格就必须开
- ❌ 找错 Array → 5.2 里 `Array` 与 `Array (Legacy)` 是两个修改器。老教程讲的 `Fit Type` / `Caps` 只在 Legacy 里有
- ❌ 环形阵列没开 `Align Rotation` → N 个副本全朝同一边，像贴上去的
- ❌ 散热孔用 `Count` 模式还想「改宽度孔数自动变」→ 要用 `Distance`（新 Array）或 `Fit Length` / `Fit Curve`（Legacy）
- ❌ 散布前源物体没 `Ctrl+A → Scale` → Scatter 出来的石头大小乱七八糟
- ❌ Scatter 用 `Density` 但物体只有 10cm → Density 是**每单位面积**，小物件改用 `Amount`
- ❌ Scatter 忘了 `Keep Surface` → 地面消失，只剩一堆实例飘着
- ❌ 不停改 `Seed` → 每次排布都变，UV 和烘焙白做。**定下就锁死**
- ❌ 在源文件里 Apply 修改器 → 迭代能力全丢。**导出时勾 Apply Modifiers**
- ❌ `Alt+D` 之后进编辑模式改了一个 → 全部跟着变（这是特性）。想单独改先 `Make Single User → Object + Data`
- ❌ 改材质颜色发现所有副本都变 → Material 也是共享数据块
- ❌ 该用 `Alt+D` 的地方用 `Shift+D`（或反之）→ 前者浪费内存、后者做不出变体
- ❌ 道具原点放几何中心 → 进引擎无法贴地摆放。规则：道具底面正中 / 门铰链 / 角色脚下
- ❌ 先 Apply Scale 再 Set Origin → 顺序反了。正确：**Set Origin → Ctrl+A Scale → Ctrl+A Rotation**
- ❌ 场景组装文件里 `Ctrl+A → All Transforms` → 所有道具塌到世界原点。**只有单资产文件才 Apply Location**
- ❌ 不改名就导出 → 引擎里一片 `Cube.001`。规范：`Prop_<名称>_<变体>_<序号>`
- ❌ 删了物体不 Purge → 孤儿数据堆积，文件越滚越大
- ❌ 贴图用绝对路径 → 换电脑全丢 → `Make Paths Relative` 或 `Pack`
- ❌ Apply / 展 UV / 烘焙之前不 `Save Incremental` → 做坏了回不去

## UV（Stage 3）

- ❌ 不标缝合边直接 Unwrap → 展开一团乱麻（⚠️ 只有 `Unwrap` 看 seam；`Smart UV Project` / `Cube Projection` / `Lightmap Pack` 自己算切口）
- ❌ 岛排太挤 → 烘焙时像素溢出（mipmap 一到就露馅）→ padding 取贴图边长的 0.4%–0.8%
- ❌ 忘了 UV 有方向 / 手性 → 贴图镜像 → 查 `Select → All by Trait → Winding`，或贴一张带「F」的测试图
- ❌ **照 4.x 老教程关掉 UV Sync** → 5.x 同步已重写且默认开启，关了反而看不到完整 UV 全貌
- ❌ 以为棋盘格要去网上下载 → Blender 自带：`UV 编辑器 → Image → New → Generated Type: UV Grid`
- ❌ 检查图分辨率 ≠ 最终贴图分辨率 → padding 与纹素密度判断全错
- ❌ 无条件追求「零重叠」 → 不烘焙时，重复结构（螺丝/散热孔/对称件）的**故意重叠是正确的优化**
- ❌ 先 Pack 再统一密度 → 密度一改岛的像素尺寸就变，之前算好的 padding 全废
- ❌ `Minimize Stretch` 的 Blend 直接给 0 → 拉伸是小了，但岛被拉变形，硬表面的横平竖直全没了
- ❌ Mirror 没 Apply 就展 UV → 只有半边有 UV，导出后另一半是乱的
- ❌ 分离件各自占满 0–1 → 应共享同一张图集
- ❌ 把 `Mark Sharp` 当成 `Mark Seam` → 都在 `Ctrl+E` 菜单里；Sharp 管法线，Seam 管 UV
- ❌ UV Maps 面板没切换就展开 → 把主 UV 覆盖了（高亮的那套 = 当前编辑对象）
- ❌ 为了利用率把把手/锁扣压得很小 → 玩家视线焦点最糊，本末倒置

## 材质 / 烘焙（Stage 4）

- ❌ Normal 贴图设成 sRGB → 光照全错。**Non-Color**
- ❌ 烘焙前没 Apply Scale / 没清重叠 UV → 出一堆黑块
- ❌ 一个道具 8 个材质 → 8 次 draw call
- ❌ 烘焙完不存盘 → 贴图丢失（**不报错，重开就没了**）
- ❌ 把阴影 / AO 画进 Base Color → 引擎里叠加真实光照后变"脏抹布"
- ❌ 金属给暗色 Base Color（→ 脏塑料）／非金属给亮色（→ 自发光感）
- ❌ Metallic 给 0.5 当"半金属" → 物理上不存在；用纯黑白遮罩
- ❌ Roughness 给 0 或 1 → 0 疯狂闪烁、1 发灰；卡在 0.05–0.95
- ❌ **5.x 起没选中目标 Image Texture 节点就点 Bake** → 静默失败（只烤 selected+active）
- ❌ 烘焙选择顺序反了（低模先选）→ active 不是低模 → 全错但不报错
- ❌ 高模被隐藏 → 不参与烘焙 → 烤出来是低模自己
- ❌ Ray Distance 抄教程的固定值 → 尺度一变就错；按二分法试（黑块=太小，糊=太大）
- ❌ **找 Curvature 烘焙类型** → 没有这个类型 → 用 `Emit` + `Pointiness`
- ❌ Normal 图直插 Principled 的 Normal 输入（没过 Normal Map 节点）→ 凹凸全错
- ❌ 乱改 Swizzle → 凹凸反了；默认 `+X/+Y/+Z` 就是 glTF/Unity/UE/Godot 通用约定
- ❌ Margin 给太小 → 接缝在 mipmap 下漏黑边（1024 给 8–16px）
- ❌ 用 Mix RGB 把 AO 乘进 Base Color → Blender 好看，导出全丢（要乘就乘进贴图文件）
- ❌ AO 没接 `glTF Material Output › Occlusion` → 引擎里没 AO，白烤
- ❌ ORM 通道排错（AO 塞进 G）→ 粗糙度变遮蔽，全场发黑
- ❌ Compositor 合成 ORM 时 File Output 的 Color Space 忘了改 Non-Color
- ❌ Normal / ORM 用 JPEG → 块状伪影；只给 BaseColor 用
- ❌ 在 Normal 图上直接手绘 → 法线数据被破坏（法线只由烘焙产生）
- ❌ 用渲染截图当 Albedo → 视图变换（ACES/AgX）被烤进贴图，引擎二次映射

## 资产规范 / 面数预算（Stage 6）

- ❌ 把 Blender 报的 Faces 当 tri → Quad 模型实际 ×2 → 超预算一倍还不知道（用 `Ctrl+T` 三角化数）
- ❌ 场景文件里 `Ctrl+A → All Transforms` → 所有道具塌到世界原点（**只有单资产文件才 Apply Location**）
- ❌ 先 Apply Scale 再 Set Origin → 顺序反了（正确：Set Origin → Scale → Rotation）
- ❌ 只改对象名不改 Mesh 数据名 → 引擎里/Append 时还是 `Cube.001`
- ❌ 不做真实尺寸、全靠缩放 → 进引擎每个资产都要手动调，且纹素密度全不一样（建 `REF_1m`）
- ❌ 用负缩放（`S X -1`）做镜像 → 法线翻转 · 引擎报 negative determinant → 用 Mirror 修改器并 Apply
- ❌ Bevel 给 3–4 段 / SubD 视口 2 级就当最终面数 → 导出 Apply Modifiers 之后才是真数（SubD 2 级 ×16）
- ❌ 把螺丝做成实体 → 20 个螺丝 ≈ 2000 tri → 烤进 Normal 贴图
- ❌ 为了省 draw call 把整个场景 `Ctrl+J` 合成一个 → 视锥剔除失效，帧率更差（按空间区域合并）

## 有机资产 / 雕刻 / 重拓扑（Stage 5）

- ❌ **雕刻前没 `Ctrl+A → Rotation & Scale`** → Scale≠1 时笔刷是椭圆形，对称侧还雕不动
- ❌ **照 4.x 老教程的笔刷数值** → **5.0 起 Brush Size 表示直径，不再是半径**，观感大一倍
- ❌ **进了 Dyntopo 再去展 UV / 画顶点色** → 全丢。**UV 永远排在 Voxel Remesh 与 Dyntopo 之后**
- ❌ **Voxel Remesh 之后去找 UV** → 官方明确会丢所有 mesh data layers
- ❌ **Voxel Remesh 出不来结果** → ① 网格有洞且洞 > voxel size；② 物体上挂着 Multiresolution 修改器（**直接不支持**）；③ Remesh 无视修改器生成的几何
- ❌ **开了 Adaptivity 又想要干净 quad** → Adaptivity > 0 必然引入三角面，并禁用 Fix Poles
- ❌ **长期开着 Dyntopo** → 越雕越慢 + UV/顶点色悄悄没了（5.2 起还没有二次确认提醒）
- ❌ **retopo 时 `Project Individual Elements` 没开** → 整组顶点一起挪向平均位置，新网格直接变形
- ❌ **用 X-Ray 代替 Retopology 叠层** → 满屏重影，很容易参考到背面的轮廓
- ❌ **一格一格贴着细节铺 retopo** → 比例必错。**先拿大格子圈住轮廓，再细分**
- ❌ **低模没完全包住高模就去烘焙** → 局部永远打不中射线 → 黑块
- ❌ **以为 Normal 图能改剪影** → 不能。Normal 只改面内明暗，**轮廓不对只能加面数**
- ❌ **A 路线（低模就是 Multires 的 Level 0）还去设 Cage** → 不需要。`Bake from Multires` 直接绕开 Cage 和对齐
- ❌ **B 路线想用 `Bake from Multires`** → 它只认同一个物体自己的 base level ↔ 最高 level
- ❌ **烘焙一出问题就先做 Cage** → 顺序反过来：先查 Apply Scale → UV 重叠 → 对齐 → Ray Distance 二分，最后才是 Cage
- ❌ **顶点色导出 GLB 后变白** → 材质节点树没引用这个属性，导出器就不导；且**没有任何报错**，必须重新导入 GLB 检查
- ❌ **重拓扑 / Remesh 前没 `Ctrl+Alt+S` 存增量** → 这两个都是不可逆操作

## 导出（Stage 6）

- ❌ 导出没勾 Apply Modifiers → SubD / Bevel 全丢
- ❌ 导出 Tangents → 引擎重算后反而出接缝
- ❌ UE5 忘记 Import Uniform Scale = 100（GLB 是米，UE 是厘米）
- ❌ 管线没验证就量产 → 游戏美术最常见翻车方式
- ❌ 在源文件里 Apply 修改器 → 迭代能力全丢 → 用导出时的 `Apply Modifiers`（例外：Mirror 展 UV 前必须 Apply）
- ❌ 靠"隐藏"物体来排除 → 各版本导出器行为不一致 → 用 `Limit to: Selected Objects`
- ❌ 忘了删 Empty / 参考图 / `REF_*` → 引擎里多一堆空节点
- ❌ 贴图没存盘就导出 → GLB 里没图，**且不报错**
- ❌ 盲目开 Draco → 引擎不支持 = 导入失败；量化位数太低 = 精细小物件抖动（Godot ✅ / Three.js ✅ / Unity glTFast ✅ / UE5·Bevy 需实测）
- ❌ 在 Blender 阶段压贴图 → 交给引擎的平台压缩（BC / ASTC / VRAM Compressed）
- ❌ 关掉 `+Y Up` → 模型躺倒（glTF 规范是 Y-up）
- ❌ 盲目相信"角色必须 FBX" → 现代引擎 glTF 的 skin + animation 已成熟，**先试 GLB**
- ❌ FBX 不看单位就量产 → 换引擎/版本就错 → 每次跑 `REF_1m` 实测倍率
- ❌ `Add Leaf Bones` 保持默认 ON → 引擎里多出几十根 `_end` 尾巴骨
- ❌ 顶点权重超过 4 根骨骼 → glTF 超规范，会被处理或报错（`Weight Paint → Limit Total`）
- ❌ 法线凹凸反了就去 Blender 改 Swizzle → 应在 UE 侧勾 `Flip Green Channel`，Blender 保持 `+X/+Y/+Z` 默认约定
- ❌ 跳过第三方查看器直接怪引擎 → 排错方向从一开始就错（用 glTF Validator / Babylon Sandbox）
- ❌ 用 Rendered 视图当引擎对比基准 → 视图变换（ACES/AgX）会骗你，用 Material Preview
- ❌ 只验证一次就认为"管线通了" → 换引擎 / 开 Draco / 带骨骼 / 带动画都要重验一次
- ❌ 验证通过但不记录 → 下次重新踩同一个坑（把设置写进 `07-资产规范与引擎导出/笔记.md` 的「我的记录」）

## 场景 / 几何节点 / 作品集（Stage 7）

- ❌ 不搭灰盒直接摆道具 → 比例错了全部重摆。**先用 Cube 定体积和相机**
- ❌ 相机最后才定 → 细节做完了发现构图是废的 → **灰盒阶段就定死**
- ❌ 道具尺度凭感觉 → 进引擎后人比门矮 → 用真实米数（室内门 2.0–2.1m / **仓库 2.5–3.5m**）
- ❌ 照 3.x/4.x 教程找 `Align Euler to Vector` → 5.x 是 **`Align Rotation to Vector`**
- ❌ 以为 `Scatter on Surface` 是 Array 的子功能 → 它是 5.0 新增的**独立修改器**（共 6 个新 GN 修改器：Array / Scatter on Surface / Instance on Elements / Randomize Instances / Curve to Tube / Geometry Input）
- ❌ **几何节点实例与属性面板 `Instancing` 混用** → 手册明确不支持，行为不可预期
- ❌ **嵌套实例超过 8 层** → 渲染不出来也不报错 → 节点树末尾 `Realize Instances`
- ❌ `Distribute Points on Faces` 的 Density 抄教程固定值 → 它是**每平方米点数**，地形面积一变全错
- ❌ 用 `Collection Info` 不开 `Pick Instances` → 每个点放整个集合，面数 × N
- ❌ 一上来就 `Realize Instances` → 视口当场卡死 → **能不 Realize 就别 Realize**
- ❌ 不做坡度筛选 → 陡崖上长满东西，一眼假
- ❌ 散布密度均匀 → 像个网格 → 用 Noise 做密度遮罩
- ❌ 按类型分组（所有箱子一个 Collection）→ 包围盒横跨全场 → **永不被剔除**
- ❌ 以为 `Alt+D` 能省 draw call → 它只省内存，draw call 一个不少
- ❌ 导出场景忘了 `Apply Modifiers` → **几何节点散布整个消失**（散了个寂寞）
- ❌ 开 `GPU Instances` 但实例带子物体 / 跨父物体 → 静默回退成展开几何，**不报错**
- ❌ 给 Godot 开 `GPU Instances` → 它不支持 `EXT_mesh_gpu_instancing` → Realize + Draco
- ❌ 只看 Blender 视口流畅就以为引擎也流畅 → 必须真的导进去跑一次看帧率
- ❌ 只挂 HDRI 就出图 → 发灰、没立体感 → **缺主光（Key）**
- ❌ HDRI 色彩空间设成 sRGB → 整体发灰 / 过曝 → **Non-Color**
- ❌ `Sun` 强度给 1 → 几乎没光 → 典型值 **2–5**
- ❌ `View Transform` 用 Standard → 高光死白 → 用 AgX / Filmic / ACES
- ❌ 作品集只出 Beauty 图 → 看不到拓扑和面数，等于没展示 → 4 张齐
- ❌ 线框图用视口截图 → 带网格地面和叠加层，一看就是截图 → 单独 `F12` 渲染
- ❌ 面数自己估 / 用 Faces 不用 Tris → 用 **Statistics 叠加层读 Tris**

## 绑定与动画（支线）

> 详见 [`../支线/绑定与动画/笔记.md`](../支线/绑定与动画/笔记.md)（枢纽 + 01–09）。

**概念类**

- ❌ 在 Edit Mode 摆姿势做动画 → 改的是 **rest pose**，导出后绑定姿势全变；摆姿势要在 **Pose Mode**（`Rest Position` 显示开关是排查神器）
- ❌ 顶点组名 ≠ 骨骼名（差一个字符）→ 那根骨完全没效果，**且不报错**。改骨骼名后必须同步改顶点组名
- ❌ 骨骼没勾 `Deform` → 不生成顶点组 → 那根骨不管事；反过来控件骨**不该**勾 Deform
- ❌ `Ctrl+P` 选择顺序反了（先选骨架）→ 父级挂反；**最后选的必须是骨架**
- ❌ 绑定前忘了 `Ctrl+A → Rotation & Scale`（网格和骨架**两边都要**）→ 导出后权重扭曲
- ❌ 多个 root 骨 → glTF 的 `Remove Armature Object` 会失效

**权重类**

- ❌ 以为自动权重能一次搞定 → 它只是「第一个猜测」，真正做资产都要手刷
- ❌ 忘了 `Weights → Normalize All` → 权重和 ≠ 1，动画幅度「手感不对」却找不到原因
- ❌ 忘了 `Weights → Limit Total = 4` → Blender 里正常，引擎里只认前 4 根骨
- ❌ 给了 4 以外的值（2/3/6）给 `Bone influences` → 手册明说除 **4 或 8** 外很多查看器显示异常
- ❌ `Bone Heat Weighting: failed to find solution` 就去删骨头 → 90% 是网格脏：`M → By Distance` + `Shift+N` + 删内部面/不连通碎块 + Apply Scale
- ❌ 一片**纯蓝**的顶点 → 权重 = 0 → 这些点不会跟着任何骨动 → `Weights → Assign` 补上
- ❌ 一边开 X-Axis Mirror 一边只刷一侧 → 左右权重不一致；对称要用 `Weights → Mirror`（依赖 `.L/.R` 命名）
- ❌ 刷完权重又回去改几何，却不重跑收口流程 → 新顶点影响数可能又超 4。**动了几何就重跑 Clean → Normalize All → Limit Total**

**轴向 / 命名类**

- ❌ 不跑 `Ctrl+N`（Recalculate Roll）就刷权重 → 关节弯向事后才发现不对
- ❌ 左右后缀自创写法（如 `L_upper_arm`、`upperarm_L`）→ X-Axis Mirror 与 `Weights → Mirror` 全部失效，还以为是插件 bug → 统一用 `.L` / `.R`
- ❌ 以为导出后骨骼歪的问题 5.x 会自己修 → **不会**，FBX 靠导出面板 `Primary / Secondary Bone Axis` 手动配（5.0 改的是 FBX **导入器**，不是轴向）

**动画编辑类**

- ❌ **5.2 起 `Only Insert Available` 默认开启** → 按 `I` / 开着自动关键帧却什么都没发生 → `Preferences → Animation → Keyframes` 关掉
- ❌ 只在 Dope Sheet 里看，从不进 Graph Editor → 动画永远机械生涩（手感全在曲线里）
- ❌ 循环动画靠 Cyclic F-Modifier 而不改首尾帧 → Blender 里看着循环，导出后引擎里跳一下（**modifier 不参与导出**）
- ❌ 多个 Action 堆在文件里但没 Push Down 进 NLA → 导出只有一条
- ❌ Auto Key 一直开着 → 回去调模型时顺手污染了动画曲线
- ❌ 导出前忘了把时间轴拨回起始帧 → 某些导出器从当前帧取样，动画起点偏了

**形状键类**

- ❌ 做完形状键又去改拓扑（加点 / 删点 / Boolean）→ 所有形状键错位失效，且常常不立刻报错
- ❌ 乱动 Basis → 所有相对键整体偏掉
- ❌ 在 Object Mode 拖滑杆以为在编辑形状 → 只在 **Edit Mode** 里改顶点
- ❌ 以为 FBX 能带形状键 → 5.2 的 FBX 导出器**静默不写** `Vertex shape keys`；要用 morph target 就走 GLB

**约束 / 导出类**

- ❌ 以为约束会跟着导出 → 引擎里骨骼完全不动 → 导出前必须 `Pose → Animation → Bake Action`（**Visual Keying ON · Clear Constraints ON · Frame Step 1**）
- ❌ Pole Angle 不调就怪 IK 不稳定 → IK 翻转/抖动九成是 Pole Target 与 Pole Angle 没设对
- ❌ 直接导出 Rigify 原始骨架 → 引擎里多出几百根骨 → 勾 `Export Deformation Bones only`（FBX 是 `Only Deform Bones`）
- ❌ FBX 开着 `Add Leaf Bones` → 引擎里多一堆末端小骨
- ❌ 以为导出成功 = 能用 → **必须进引擎播一遍**；绑定是沉默失败最多的一块，它不报错，它只是不动
- ❌ 每次改骨骼之前不 `Save Incremental` → 绑定是关联状态，改错了回不去
