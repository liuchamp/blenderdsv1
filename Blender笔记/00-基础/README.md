## macOS 备忘

- `Ctrl` 大多可用 `Cmd` 替代，但**不是全部**——与系统快捷键冲突的会失效（见 `Blender快捷键.md` 第 38 节）。
- 快捷键对不上时按 `F3` 搜命令名，不要死记位置。
