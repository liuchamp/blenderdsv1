# 支线 · 绑定与动画（8–12h）

> 什么时候开：**做角色资产之前**。静态道具不需要。

## 必学清单

- [ ] Rigify 插件（`Preferences → Add-ons` 勾选）
- [ ] 骨骼基础：骨骼层级、父子关系、Pose Mode
- [ ] 权重绘制（Weight Paint）与自动权重的问题排查
- [ ] IK / FK 基础
- [ ] 关键帧与 Dope Sheet / Graph Editor
- [ ] 动作导出：FBX（5.0 重做了骨骼轴向处理）

## 练习

- 给一个简单道具（如箱子盖）做骨骼 + 开合动画
- 角色支线：Rigify 生成骨架 → 权重 → 简单走路循环
