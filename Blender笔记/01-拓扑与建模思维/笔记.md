## 必学清单

- [ ] Edge Loop vs Edge Ring：`Alt+LMB` 选环 / `Ctrl+Alt+LMB` 选圈
- [ ] **Edge Slide `G G`**：拓扑不变，只重新分配空间
- [ ] Loop Cut 的两次左键语义：第一次锁环、第二次定位，中间可右键居中
- [ ] **支撑线（Support Loop）**：`Ctrl+R` 越靠近边缘 → SubD 后越硬；越远 → 越软
- [ ] Subdivision Surface 修改器 + `Shade Auto Smooth`（对象右键菜单）
- [ ] 法线控制：`Shade Auto Smooth` + `Mark Sharp`（都在 `Ctrl+E` 边菜单）
- [ ] **Bevel Weight**（`Ctrl+E → Edge Bevel Weight`）：一个修改器实现多种倒角宽度
- [ ] 拓扑体检：三角面、N-gon、极点（pole）识别；`Mesh → Clean Up`
- [ ] LoopTools：Space / Circle / Flatten 解决「线不均匀」「圆不圆」

## 验收标准

- [ ] 不看教程，3 分钟内把 Cube 做成**边缘锐利但整体平滑**的圆角方块（SubD + 支撑线）
- [ ] 能说出「为什么这个角糊了」，并指出该在哪加线
- [ ] `Mesh → Clean Up` 检查：无孤立顶点、无内部面

## 常见坑

- ❌ 为「模型更精细」疯狂加线 → 越密越难改。**先用最少的线把形状定住**
- ❌ 在 Object Scale ≠ 1 的状态下建模 → 每次 `Ctrl+A → Scale`
- ❌ SubD 后形状崩了就删线重来 → 先检查支撑线距离
