## 一、怎么用这套目录

1. **每开一个 Stage，就在对应目录的 `笔记.md` 里写**。文件已经预填了「必学清单 / 练习项目 / 验收标准 / 常见坑」，你只需要勾清单 + 补自己的记录。
2. **每阶段结束时写一次「阶段复盘」**（模板见 [_模板/学习笔记模板.md](_模板/学习笔记模板.md)），把踩过的坑和卡点落成文字。
3. **练习文件放 `资产/练习文件/`，导出成品放 `资产/导出成品/`，参考图放 `资产/参考图/`**，目录名里带 Stage 前缀，方便回查。
4. **速查类内容不进 Stage 目录**，统一放 [`速查/`](速查/)，避免以后找不到。

## 五、每周配比（三档都适用）

- **70% 做项目**：实际动手做练习项目，看教程 ≠ 学会
- **20% 学新知**：只看本周要用到的概念
- **10% 复盘**：回看上周模型，找 3 个可改进点，写进笔记

单次动手不超过 45 分钟就切一次 —— 建模高度依赖手眼协调，疲劳后做的东西第二天基本要返工。
